# Content blocks

A Milkyano deck is assembled from these blocks. Each block has one job, one layout and a fixed set of parts. Use the block that fits the job; do not invent a new layout for a job a block already covers.

## Slide frame (every content slide)

- **Chip** at the top margin: "● <Block name>" or "● <Section> · <n> of <total>".
- **Headline** under it: two lines, line 1 `ink` (the fact), line 2 `focus` (the turn). Takeaway, not topic.
- **Body**: one block from this page.
- **Footer** pinned 56px from bottom: left "MILKYANO" (label, 3px tracking, `muted`); right "<Client> · <page>". Page numbers on every slide, in order, starting at 01 on the cover.
- Section openers use the **cover** layout with the section name ("Marketing Audit", "Performance Report", "Social Media Report", "Creative Report", "Growth Strategy", "Technical Action Plan").

## Deck order

1. Cover → 2. The question (agenda) → 3. Audit (gap, chain, signals) → 4. Performance (stats, portfolio, channel mix) → 5. Social / Creative → 6. Strategy (verdict, priorities, rules) → 7. Plan (roadmap, actions, responsibilities) → 8. Investment → 9. Close.

## Openers

| Block | Job | Layout |
|---|---|---|
| **Cover / section opener** | Name the deck or section | Chip "Client · Month Year", 2-line title (cover style), muted one-line summary, buttons only on the main cover. Dark mode for pitches. |
| **The question** | Set the agenda | One big question in a panel, then 4–5 sub-question cards: number, question, "→ <answer area>". Each later section's chip repeats its number ("● 02 · How will we spend?"). |

## Numbers

| Block | Job | Layout |
|---|---|---|
| **Stat row** | 2–4 headline figures | number style, muted label under, optional delta badge. The problem stat in `risk`. |
| **Before → after** | One metric that moved | before (`context`) → after (`focus`/`risk`), label + period under. |
| **Stat strip** | A total split by location/segment | 4–7 tiles in a panel; the exception tile (Unallocated) in `risk` with "of <total>". |
| **Executive summary** | Period vs period | Table (Charts §4): metrics as rows, Current / Prior / YoY as columns, current column bold; one takeaway card under it. |

## Audit

| Block | Job | Layout |
|---|---|---|
| **The gap** | Platform view vs business view | Twin windows: same structure, platform left with "▲ Winning" (gain), business right with "▼ Not moving" (risk). |
| **The chain** | Where measurement breaks | Horizontal nodes: tracked steps solid (`panel`), missing steps dashed `risk` with "○ Missing". Stat row underneath. |
| **Signals** | Trends to watch | 3 cards: chip (topic), big before→after or range, muted caption, mini chart, "Do:" line, source. |
| **Method** | How we tested | 3–4 numbered cards (01–04, title, one-line question) + one takeaway card. |
| **Competitors** | Category landscape | 3 category cards: state (mature/emerging/niche as a word + `focus` only on the one that matters), key players list, "Client in H1" stat, source. |

## Performance

| Block | Job | Layout |
|---|---|---|
| **Channel mix** | Where money goes, each channel's job | Split bar (Charts §1) + legend row: channel · Rp · one fact · "Job: …". Organic/unpaid upside as a chip card. |
| **Channel cards** | Compare 3–5 channels on their own metric | Equal cards: CHANNEL label, number, one fact, divider, ROLE label, role. Top bar: `focus` = the focus channel, `context` = others, `risk` = problem. |
| **Portfolio** | Which categories earn | Sorted bar list of the deciding metric (ROAS or margin) with revenue + note per row; full scorecard in appendix. |
| **Scorecard** | Full KPI set per category | 2–3 columns, header bar `ink`, label/value rows, one note, cross-reference. Max 8 rows. |

## Social & creative

| Block | Job | Layout |
|---|---|---|
| **Leaderboard** | Top / bottom content | Ranked rows: rank, name + format, bar of engagement rate vs average line, value, tag. "Why it worked" as muted line. Average shown as dashed benchmark. |
| **Creative ranking** | Which angle wins | Sorted bars of ROAS with tags Scale / Expand / Keep / Cut. |
| **Concept grid** | Brief new creatives | 2×2 cards: image slot (portrait 3:4), type tag, Hook / Angle / Why it works / Takeaway fields. |
| **Principles** | What to carry into every brief | 3 dark cards: title, one line, evidence number (e.g. "2:1"). |

## Strategy

| Block | Job | Layout |
|---|---|---|
| **Verdict** | Scale, hold or cut | Segmented pill with the chosen state filled; two cards: Why / What would change it. |
| **Priorities** | Where to focus | Three columns: Double down (P1–P3, `focus` badges) · Test (`focus-soft`, hypothesis tag) · Deprioritise (muted list). |
| **Channel rules** | What every rupiah must do | One row card per channel: name + Rp + share, then GOAL / GUARDRAIL / DECISION RULE columns. |
| **Role matrix** | Channel × category roles | Table with pill badges: Primary (`focus`), Secondary (`focus-soft`), Test (outline), Limited (muted). |
| **Today → Target** | Show the system change | Two vertical flows side by side, today in `context`, target in `focus`, 3–5 steps each. |
| **Test vs control** | Explain an experiment | Two cards with "VS", then "Compare:" chips. |

## Plan

| Block | Job | Layout |
|---|---|---|
| **Roadmap** | Next 90 days | 3 columns (Month 1–3 or P0–P2): header card, 2–3 task cards each with ACTION and OUTCOME lines. One job per column. |
| **Gantt** | Overlapping workstreams | Month header row, 3–5 lanes, bars in `focus-soft` / `context`; bar text max 2 lines. |
| **Action table** | Technical to-do list | Table: ID (T1…), Action, What it does, Supports (P1…), Type tag (Evidence-backed `focus` / Hypothesis `risk` outline). |
| **Responsibilities** | Who does what | Two list cards: "We handle" (`focus` top bar) / "We need from you" (`risk` top bar), plus a vertical Today→Goal stepper. |

## Close

| Block | Job | Layout |
|---|---|---|
| **Investment** | Pricing | Two plan cards; the recommended one dark with a "Recommended" gain badge. Prices in number style; inclusions as ✓ list. |
| **Statement / close** | The one sentence to remember | Dark slide, cover style, the sentence in two tones; optional 5-stage system strip above it. |

## Callouts (only three kinds)

1. **Do line** — "**Do:** <action>", `focus` label, inside a card or under a chart.
2. **Takeaway card** — `panel` card, one sentence, the first clause bold `focus`. Max one per slide.
3. **Note bar** — slim bar for definitions ("'Current' below = …"), `focus-wash` fill, label style.

Never: black bars with white text, brown bars, red footnotes, "Key Highlight:" boxes, quotes in italic boxes.
